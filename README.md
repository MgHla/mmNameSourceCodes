
# mmName Project (Souce Codes)

**mmName** သည် အင်္ဂလိပ်ဘာသာဖြင့် ရေးသားထားသော မြန်မာလူမျိုးအမည်များနှင့် အမျိုးသားမှတ်ပုံတင် (NRC) နံပါတ်များကို မြန်မာစာလုံးပေါင်းသို့ စနစ်တကျ ပြောင်းလဲပေးသည့် Web Application ဖြစ်သည်။

🌐 **Live Demo:** [https://mmname.mghla.net/](https://mmname.mghla.net/)

##  Key Features

-   **Myanmar Name Conversion (အမည် ပြန်ဆိုခြင်း):** English လို ရေးထားသော မြန်မာအမည်များကို မြန်မာစာလုံးပေါင်းသို့ ပြန်ဆိုပေးခြင်း။
    
-   **NRC Converter (မှတ်ပုံတင်နံပါတ် ပြန်ဆိုခြင်း):** English စာလုံး/ကိန်းဂဏန်းများဖြင့် ရေးသားထားသော မှတ်ပုံတင်နံပါတ်များကို သက်ဆိုင်ရာ **တိုင်း/ပြည်နယ်**၊ **မြို့နယ်**၊ **အမျိုးအစား** နှင့် **နံပါတ်** အလိုက် မြန်မာလို အသေးစိတ် ခွဲခြားပြောင်းလဲပေးခြင်း။
    
-   **Batch Processing:** အမည်များစွာကို တစ်ပြိုင်နက်တည်း ပြောင်းလဲနိုင်သည့် စနစ် ပါဝင်ခြင်း။

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)

- **Backend / Database**: Supabase

- **Serverless / Hosting**: Cloudflare Workers

## 📖 Mapping Data Source
အမည်များ ပြောင်းလဲရာတွင် အသုံးပြုထားသည့် English to Myanmar Name Mapping Data များကို Open Source အဖြစ် အောက်ပါ Repository တွင် လေ့လာကြည့်ရှုနိုင်ပါသည်-👉 GitHub Repository: [MgHla/Myanmar-Name_en-2-mm](https://github.com/MgHla/Myanmar-Name_en-2-mm)
