# mmName Docker Web App

ဒီ mmName Project က Docker ကို သုံးထားတဲ့ LAMP (PHP + MySQL) Web Application တစ်ခုဖြစ်ပါတယ်။

## ကြိုတင်လိုအပ်ချက်များ (Prerequisites)
- Docker နှင့် Docker Compose ကို သင့်စက်မှာ ထည့်သွင်းထားရပါမည်။
- Port 8081, 8082 နှင့် 3307 တို့ကို အခြား Program များက သုံးမထားပါစေနှင့်။
